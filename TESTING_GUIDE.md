## 🎯 Типы тестирования

### 1. Unit Tests (Модульные тесты)
Тестируют отдельные функции и классы в изоляции.

```dart
// Пример: Тест валидации пароля
void main() {
  group('PasswordValidator', () {
    test('should return true for valid password', () {
      final validator = PasswordValidator();
      expect(validator.validate('Test@1234'), true);
    });

    test('should return false for short password', () {
      final validator = PasswordValidator();
      expect(validator.validate('Test@12'), false);
    });
  });
}
```

### 2. Widget Tests (Тесты виджетов)
Тестируют UI компоненты.

```dart
// Пример: Тест кнопки входа
void main() {
  testWidgets('LoginButton should be enabled when email and password are valid', 
    (WidgetTester tester) async {
    await tester.pumpWidget(MyApp());
    
    // Вводим email
    await tester.enterText(find.byType(TextField).first, 'test@example.com');
    
    // Вводим пароль
    await tester.enterText(find.byType(TextField).last, 'Test@1234');
    
    // Проверяем, что кнопка включена
    expect(find.byType(ElevatedButton), findsOneWidget);
  });
}
```

### 3. Integration Tests (Интеграционные тесты)
Тестируют полные сценарии использования приложения.

```dart
// Пример: Тест полного процесса входа
void main() {
  testWidgets('User can login and see feed', (WidgetTester tester) async {
    await tester.pumpWidget(MyApp());
    
    // Вводим учетные данные
    await tester.enterText(find.byType(TextField).first, 'test@example.com');
    await tester.enterText(find.byType(TextField).last, 'Test@1234');
    
    // Нажимаем кнопку входа
    await tester.tap(find.byType(ElevatedButton));
    await tester.pumpAndSettle();
    
    // Проверяем, что мы на экране ленты
    expect(find.byType(FeedScreen), findsOneWidget);
  });
}
```

## 🔒 Тестирование безопасности

### 1. Проверка хранилища токенов
```bash
# Проверь, что токены хранятся в SecureStorage, а не в SharedPreferences
flutter logs | grep -i "token"

# Должно быть:
✅ [INFO] Token saved to SecureStorage

# Не должно быть:
❌ [INFO] Token saved to SharedPreferences
```

### 2. Проверка HTTPS
```bash
# Проверь, что все запросы идут по HTTPS
flutter logs | grep -i "http://"

# Не должно быть:
❌ http://api.colibri.com
```

### 3. Проверка логирования
```bash
# Проверь, что логи не содержат чувствительных данных
flutter logs | grep -i "password\|token\|secret"

# Не должно быть:
❌ [INFO] Password: Test@1234
❌ [INFO] Token: eyJhbGc...
```

### 4. Проверка валидации пароля
```
Требования:
✅ Минимум 12 символов
✅ Минимум 1 заглавная буква
✅ Минимум 1 строчная буква
✅ Минимум 1 цифра
✅ Минимум 1 спецсимвол (!@#$%^&*)

Примеры:
✅ Test@1234567 - Валидный
❌ test@1234567 - Нет заглавной буквы
❌ Test1234567 - Нет спецсимвола
❌ Test@123 - Слишком короткий
```
